### 🚀 Мои проекты

#### 1. ⚡ PokéFinder — Поиск покемонов по ID
Веб-приложение для моментального поиска информации о покемонах по их уникальному номеру или имени с использованием публичного API.
- **Функционал:** мгновенный поиск по ID, отображение статов, типов, способностей и спрайтов.
- **Стек:** HTML, CSS, JavaScript, Fetch / REST API (PokéAPI).
- 🔗 **[Посмотреть код](https://github.com/ТВОЙ_НИК/pokemon-finder)** | 🌐 **[Демо](https://ТВОЙ_НИК.github.io/pokemon-finder)**

<br>

#### 2. 👟 SneakerStore — Интернет-магазин кроссовок
Современный e-commerce сайт для продажи кроссовок с удобным каталогом, фильтрацией и корзиной покупок.
- **Функционал:** каталог с фильтрами по брендам и размерам, карточка товара, интерактивная корзина с подсчетом суммы, полная адаптивность.
- **Стек:** HTML5, CSS3 (Flexbox/Grid), JavaScript / jQuery.
- 🔗 **[Посмотреть код](https://github.com/ТВОЙ_НИК/sneaker-shop)** | 🌐 **[Демо](https://ТВОЙ_НИК.github.io/sneaker-shop)**
